# LUMEN — parcours (écran par écran)

Les écrans sont des `<section class="screen">` dans le `<main>` de `index.html` ; les feuilles (pause, fin, niveau, récompense) sont des voiles posés au-dessus.

1. **Premier lancement** → tutoriel guidé directement sur le plateau (bulle « coach », bouton « Continuer »).
2. **Accueil** (`#home`)
   - En-tête : rang (→ Statistiques), éclats (→ Boutique), Réglages.
   - Titre LUMEN, rangée de la série (→ Missions).
   - **Jouer** → partie d'Aventure au niveau en cours.
   - Carte **Aventure** → carte des niveaux. Tuiles **Classique** et **Défi du jour**. Bandeau **Événement de la semaine**.
   - Barre du bas : Missions, Boutique, Succès, Thèmes, Stats.
   - Feuille **Récompense** (série d'ouverture) à la première ouverture du jour.
3. **Carte de l'Aventure** (`#map`) → touche d'un niveau → feuille **Niveau** (objectifs, coups, étoiles) → Jouer / Fermer.
4. **Partie** (`#game`) : score, coups restants, objectifs, spectre, plateau, boosters (Pulse, Marteau, Étincelle, +5 coups).
   - Glisser le doigt d'orbe en orbe → fusion ; carte « Nouvelle orbe » à la première orbe spéciale.
   - **Pause** → Reprendre / Recommencer / Quitter la partie.
5. **Fin de partie** : étoiles, score, record, gains ; pour le Défi du jour : aperçu, série, « Partager le résultat », « Partager l'image », « Prochain défi dans … » ; Rejouer / Retour à l'accueil.
6. **Panneaux** (bouton Retour) : Boutique, Missions du jour (+ série, événement), Succès, Thèmes, Statistiques.
7. **Réglages** : langue, sons, musique, vibrations, rejouer le tutoriel, code de sauvegarde (copier / importer), réinitialisation (double confirmation), autres jeux d'Aulit, lien « Confidentialité, conditions et mentions légales ».
8. **Pages annexes** : `privacy.html` (FR + `#english`), `404.html`.
